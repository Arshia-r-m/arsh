How this site is built

2026-11-25 · 1 min read · #meta #self-hosting

This site is plain HTML and one stylesheet. There is no JavaScript, and the page tells your browser to refuse any: look for Content-Security-Policy in the source.

Writing

Each post is a Markdown file in the repo, under content/posts/. Zola turns them into HTML, along with the post list, the tag pages and the feed.

Publishing

  1. A change goes in through a pull request. CI builds the site and rejects anything with scripts in it.
  2. When the pull request is merged, CI builds again and pushes the HTML to a separate site branch.
  3. My server checks that branch every two minutes, checks the files itself, and swaps the new version in atomically.

GitHub never logs in to the server. The server only reads a public repo.
